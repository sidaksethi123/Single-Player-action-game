Single Player Action Game

A single-player 2D action game built using Java and the Bagel game engine. The player navigates a sprite-based world, collects keys, earns money, upgrades weapons, and eliminates enemies to progress.

## 🎯 Gameplay

- Explore a 2D map populated with interactive sprites
- Collect keys to unlock new areas
- Defeat enemy sprites using weapons
- Earn money from eliminations
- Upgrade weapons to increase combat effectiveness
- Progress by clearing enemies and unlocking paths

## 🛠️ Tech Stack

- Java
- Bagel Game Engine
- Object-Oriented Programming (OOP)

## Features

- Sprite-based rendering system
- Collision detection between player, enemies, and objects
- Inventory system (keys, money)
- Weapon upgrade mechanics
- Enemy behaviour and combat system
- Real-time game loop and state management


## 🚀 How to Run

1. Clone the repository  
2. Compile the project:
   javac *.java  
3. Run the game:
   ShadowDungeon.java
